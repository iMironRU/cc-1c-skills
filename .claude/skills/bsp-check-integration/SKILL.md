## Описание

Статический анализ XML-исходников конфигурации на корректность внедрения подсистем
библиотеки БСП. Не требует запущенной платформы 1С — работает с файлами напрямую.

## Команда

```bash
python3 .claude/skills/bsp-check-integration/scripts/bsp_check_integration.py [параметры]
```

## Параметры

| Параметр | Описание |
|----------|----------|
| `--src <path>` | Каталог исходников XML (авто-поиск: `src/cf`, `src`, `1c/standalone/src`) |
| `--subsystem <name>` | Проверить только одну подсистему |
| `--severity error\|warning\|info` | Минимальный уровень вывода (умолч: `warning`) |
| `--list` | Список всех доступных проверок |

## Доступные проверки

| Подсистема | Что проверяется |
|------------|-----------------|
| `РаботаСФайлами` | Справочники *ПрисоединенныеФайлы: реквизиты, определяемые типы, вызовы в формах владельцев |
| `КонтактнаяИнформация` | ТЧ КонтактнаяИнформация: состав реквизитов, типы, регистрация в ОпределяемыхТипах |
| `ЭлектроннаяПодпись` | Объекты с реквизитом ПодписанЭП → должны быть в ОпределяемыйТип.ПодписанныйОбъект |
| `Свойства` | ТЧ ДополнительныеРеквизиты: состав, типы, вызовы в форме объекта |
| `ПодключаемыеКоманды` | Объекты с ДобавитьКоманды*: вызовы в форме, процедуры Подключаемый_* |
| `ВерсионированиеОбъектов` | Объекты в переопределяемом → в ОпределяемыйТип.ВерсионируемыйОбъект |
| `ОбновлениеВерсииИБ` | Регистрация обработчиков обновления |
| `ДатыЗапретаИзменения` | Вызов ПриЗаполненииИсточниковДанных в переопределяемом |
| `Мультиязычность` | Вызовы МультиязычностьСервер в формах мультиязычных объектов |
| `УчетОригиналовПервичныхДокументов` | Процедуры и вызовы в формах документов с оригиналами |
| `ВариантыОтчетов` | Наличие ДобавитьКомандыОтчетов в менеджере отчётов |

## Примеры

```bash
# Полная проверка всех подсистем
python3 .claude/skills/bsp-check-integration/scripts/bsp_check_integration.py

# Только работа с файлами
python3 .claude/skills/bsp-check-integration/scripts/bsp_check_integration.py --subsystem РаботаСФайлами

# Только ошибки
python3 .claude/skills/bsp-check-integration/scripts/bsp_check_integration.py --severity error

# Список доступных проверок
python3 .claude/skills/bsp-check-integration/scripts/bsp_check_integration.py --list
```

## Коды выхода

- `0` — нет ошибок (предупреждения не влияют)
- `1` — найдены ошибки или каталог исходников не найден

## Ограничения

Проверки, требующие запущенной 1С (запросы к БД, предопределённые элементы),
не реализованы — выполняется только статический анализ XML и BSL файлов.
Для полной проверки используй оригинальную обработку «ПроверкаВнедренияБСП.erf».
