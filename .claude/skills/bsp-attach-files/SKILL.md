# /bsp-attach-files — Присоединённые файлы БСП

Генерирует XML справочника присоединённых файлов из БСП-эталона, регистрирует в Configuration.xml, сортирует ChildObjects.

## Usage

```
/bsp-attach-files --owner МойСправочник --new-name МойСправочникПрисоединённыеФайлы
```

## Команда

```bash
python3 "${CLAUDE_SKILL_DIR}/scripts/bsp-attach-files.py" <параметры>
```

### Параметры

| Параметр | Обязательный | Описание |
|----------|:------------:|----------|
| `--owner-name` | да | Имя справочника-владельца (напр. `Контрагенты`) |
| `--new-name` | да | Имя нового справочника (напр. `КонтрагентыПрисоединённыеФайлы`) |
| `--synonym-owner` | да | Текст для синонимов: «Присоединённые файлы (<текст>)» |
| `--demo-xml` | нет | Путь к XML эталона БСП (default: `base/bsp-demo-unpack/Catalogs/_ДемоПроектыПрисоединенныеФайлы.xml`) |
| `--src-dir` | нет | Каталог исходников (default: auto-detect `src/` или `1c/standalone/src`) |
| `--register` | нет | Зарегистрировать в Configuration.xml + sort ChildObjects |
| `--force` | нет | Перезаписать XML, даже если уже существует |

## Что делает

1. Берёт XML эталона (`_ДемоПроектыПрисоединенныеФайлы`) из БСП
2. Переименовывает: имя, ссылки на владельца, синонимы
3. Убирает pre-merge реквизиты (СтатусИзвлеченияТекста, Том, ТипХраненияФайла)
4. Упрощает составные типы (Автор/Изменил/Редактирует → только CatalogRef.Пользователи)
5. Генерирует новые UUID
6. Регистрирует в Configuration.xml (опционально)
